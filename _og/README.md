# Social Card Assets

Assets used by [jekyll-og-image](https://github.com/igor-alexandrov/jekyll-og-image) to render the posts' social cards, configured in `og_image` in `_config.yml`.

## Fonts

The cards use the same fonts as the site. libvips finds fonts by name, so they must be installed: macOS includes them, and CI copies these files to `~/.local/share/fonts`. They were downloaded from [google/fonts](https://github.com/google/fonts) and licensed under the SIL Open Font License 1.1.

| `fonts/PT_Serif-Web-Bold.ttf`          | [PT Serif](https://github.com/google/fonts/tree/main/ofl/ptserif) Bold, for titles                            | [`OFL-PT_Serif.txt`](fonts/OFL-PT_Serif.txt)             |
| `fonts/PT_Serif-Web-Italic.ttf`        | [PT Serif](https://github.com/google/fonts/tree/main/ofl/ptserif) Italic, for the description                 | [`OFL-PT_Serif.txt`](fonts/OFL-PT_Serif.txt)             |
